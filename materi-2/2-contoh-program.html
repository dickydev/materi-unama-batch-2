🎧 Class 2 — Media Elements

HTML bukan hanya untuk teks dan gambar — tetapi juga mendukung media interaktif seperti video, audio, dan konten eksternal. Sejak HTML5, media menjadi bagian resmi dari spesifikasi web modern.

🎞️ 1. Embedding Video dengan <video>

Elemen <video> digunakan untuk menampilkan video secara langsung di halaman web tanpa plugin eksternal seperti Flash.

Penjelasan:
- Atribut controls menampilkan kontrol video.
- poster menampilkan gambar preview sebelum video dimulai.
- <track> digunakan untuk subtitle agar video lebih aksesibel.
- source mendukung multi-format untuk kompatibilitas lintas browser.

Analogi: Tag <video> seperti pemutar film mini di browser — lengkap dengan tombol play, volume, dan fullscreen tanpa aplikasi tambahan.

🔊 2. Embedding Audio dengan <audio>

Elemen <audio> memungkinkan pengguna memutar file suara secara langsung di browser. Audio bisa digunakan untuk musik, narasi, podcast, atau efek suara.

Penjelasan:
- controls untuk tombol play/pause.
- preload="metadata" hanya memuat informasi dasar agar hemat bandwidth.
- Bisa menambahkan loop, autoplay, atau muted sesuai kebutuhan.
- Gunakan .mp3 untuk dukungan paling luas.

Analogi: Elemen <audio> seperti pemutar musik digital — pengguna bebas memutar atau menjeda sesuai keinginan mereka.

🌍 3. Embedding External Content dengan <iframe>

Elemen <iframe> digunakan untuk menyematkan halaman web atau konten eksternal, seperti video YouTube, peta Google Maps, atau dokumen dari luar.

Penjelasan:
- Atribut src menentukan sumber konten.
- title wajib untuk aksesibilitas screen reader.
- allowfullscreen mengizinkan mode layar penuh (khusus video).
- sandbox dapat digunakan untuk membatasi interaksi jika sumbernya bukan milik kita.

Analogi: Elemen <iframe> seperti jendela kecil di rumahmu — kamu bisa melihat dunia luar, tetapi tetap butuh pagar keamanan agar tidak dimasuki orang asing.
